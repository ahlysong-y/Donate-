# Donate-

A modern Live Stream Donation & Tipping React Native / Expo application with interactive Bakong / ACLEDA QR payments, Khmer TTS voice announcements, animated alerts, and donation sound effects.

## Features
- 💸 **Instant Donation & Tipping**: Custom amounts with quick tip presets ($1, $2, $5, $10, $20, $50).
- 🎙️ **Voice Text-to-Speech (Khmer & English)**: Speaks donor names, tipped amounts, and custom messages out loud with natural voice synthesis.
- 📱 **QR Code Payments**: Supports ACLEDA and Bakong KHQR transfers.
- 🎬 **Live Stream Alert Overlays**: Sound effects, animated donation banners, and donor leaderboards.
- 🌐 **Cross-Platform**: Built with Expo and React Native for Web, iOS, and Android.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the App
```bash
npx expo start
```
